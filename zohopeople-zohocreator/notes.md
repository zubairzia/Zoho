# Payroll Management System (Zoho Creator + Zoho People Integration)

## Project Overview

This project is a custom Payroll Management System developed using **Zoho Creator** with seamless integration to **Zoho People**. It automates payroll processing by utilizing employee data from Zoho People and managing payroll operations within Zoho Creator.

## Features

- Integration with Zoho People for employee data synchronization
- Automated payroll calculations
- Salary structure management
- Attendance and leave-based payroll processing
- Allowances and deductions management
- Payslip generation
- Payroll history and records
- User-friendly dashboard and reports

## Technologies Used

- Zoho Creator (Low-Code Platform)
- Zoho People
- Deluge Scripting
- Zoho APIs

## Purpose

The objective of this project is to simplify payroll management by reducing manual work, improving accuracy, and providing a centralized platform for payroll administration.

## Note

This repository is intended to showcase the project architecture, integration approach, and implementation. Sensitive business data, credentials, and proprietary information have been excluded.
